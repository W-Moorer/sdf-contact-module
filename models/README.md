# models — 3D Model Files

## OBJ Files

| File | Description | Source |
|------|-------------|--------|
| `cube.obj` | Cube mesh (5400 verts, 10092 tris) | Generated by `scripts/gen_meshes.py` |
| `hollow_cylinder_*.obj` | Hollow cylinder (coarse→very_dense) | Generated by `scripts/gen_meshes.py` |
| `rmd_*.obj` | Surfaces extracted from RecurDyn RMD GGEOM | Extracted by `prototype/src/importers/rmd_surface.py` |

## SDF Files

| File | Resolution | Description |
|------|-----------|-------------|
| `cube_res64.sdf` | 64³ | Cube SDF (low res) |
| `cube_res128.sdf` | 128³ | Cube SDF (medium res) |
| `cube_res256.sdf` | 256³ | Cube SDF (high res) |
| `cylinder_res*.sdf` | 64/128/256 | Cylinder SDF |

## RecurDyn Model Directories

Directories with Chinese names contain RecurDyn `.rdyn` project files with solver results (`.rplt`, `.rad`, `.req`, `.out`).
